# Boundland · jugar

Las versiones de desarrollo de Boundland (Milbit Estudios) para jugar en el navegador:
**https://ok2iatool-coder.github.io/boundland-juegos/**

| Carpeta | Qué es |
|---|---|
| `2d/` | El juego en 2D: once niveles |
| `3d/` | El Sujeto 18 en 3D (`?mapa=mundo`, `?mapa=terreno`) |
| `paso-3d/` | Prueba del paso de 2D a 3D |
| `base/` | Prueba de la base de refugiados en 2.5D |
| `muro/` | Cinemática jugable del muro |
| `industrial/` | La ciudad industrial en 2.5D |

No se edita aquí: todo lo genera `publicar.py` desde los proyectos de cada juego.
